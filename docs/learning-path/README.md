# Learning Path

## Phase 1 — No-code
Prove the basic agent loop with a small synthetic data source.

## Phase 2 — Low-code
Add LLM extraction, structured outputs, API/tool calls, validation, retries, state, and human approval.

## Phase 3 — Medium-code
Introduce reusable skills, deterministic orchestration, custom tools, evaluation harnesses, and domain logic.

## Phase 4 — Production patterns
Add observability, idempotency, access control, regression testing, rate limits, deployment, and operational runbooks.

The objective is not to collect frameworks. It is to build enough hands-on depth to make sound architecture, security, evaluation, build-vs-buy, and operating-model decisions.
